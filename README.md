## 🔭 Projetos em destaque — desenvolvidos em aula

### 🔎 Sistema de Achados e Perdidos — UNIFRAN

Sistema acadêmico para registrar, localizar e devolver itens perdidos dentro da universidade.

- Requisitos funcionais e não funcionais
- Personas e jornadas dos usuários
- Casos de uso e modelagem de processos
- Autenticação, permissões, notificações, auditoria e LGPD

### 🚗 SpotWash — Sistema de Gestão para Lava-jatos

Projeto de uma solução para administrar clientes, serviços, agenda, estoque, vendas, caixa, despesas, receitas e relatórios gerenciais.

- Planejamento do produto e definição do escopo
- Documentação funcional e técnica
- Estrutura de interface web
- Arquitetura proposta com Python, Django, React e PostgreSQL

### 💳 Sistema de Contas a Pagar

Módulo simplificado de ERP para cadastro e acompanhamento de contas, vencimentos e pagamentos.

- Levantamento e organização de requisitos
- Regras de negócio do módulo financeiro
- Modelagem de dados e processos empresariais

### 🛒 Sistema de Banco de Dados para Loja

Estrutura relacional desenvolvida em PostgreSQL para representar o fluxo central de uma loja, conectando clientes, catálogo de produtos, pedidos e seus respectivos itens. O projeto aplica conceitos essenciais de integridade e organização de dados utilizados em sistemas comerciais.

- Modelagem das entidades de usuários, produtos, pedidos e itens de pedido
- Relacionamentos consistentes por meio de chaves primárias e estrangeiras
- Preservação da integridade dos dados com `NOT NULL`, `UNIQUE` e valores padrão
- Registro do preço unitário no item do pedido para preservar o valor da venda
- Operações de cadastro, consulta e atualização de dados em múltiplas tabelas
